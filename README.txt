ميزانيتي — نسخة PWA قابلة للتثبيت على الشاشة الرئيسية

محتويات الحزمة: index.html، manifest.webmanifest، service-worker.js، وأيقونات التطبيق.

طريقة الاستخدام السريعة:
1. ارفع محتويات هذا المجلد إلى استضافة HTTPS ثابتة (مثل GitHub Pages أو Netlify). لا يكفي فتح index.html مباشرة من مدير الملفات لتثبيت PWA.
2. افتح رابط الموقع في Chrome على Android.
3. افتح قائمة ⋮ ثم اختر "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية" (قد تختلف التسمية).
4. بعد فتح التطبيق مرة واحدة عبر الرابط، سيُخزّن غلاف التطبيق للعمل دون اتصال بالإنترنت.

الخصائص: واجهة عربية RTL، تسجيل الدخل والهدف الشهري، إضافة المصاريف وتصنيفها، تقارير حسب الفئة، اختيار الأشهر السابقة، تصدير CSV ونسخ احتياطي JSON.

الخصوصية: تُحفظ البيانات في localStorage داخل متصفح/بيانات التطبيق على هذا الجهاز فقط. لا يوجد حساب مستخدم أو مزامنة سحابية أو اتصال بالبنك. خذ نسخة JSON احتياطية قبل مسح بيانات المتصفح أو إلغاء تثبيت التطبيق.

ملاحظة مهمة: هذه حزمة PWA جاهزة للنشر، وليست APK. يتطلب التثبيت كتطبيق ويب عادةً نشرها على HTTPS أولًا.
